# 重置已有内网穿透配置

## 适用场景

当用户明确要求清理、卸载、重置或重新开始已有的内网穿透配置时，使用本模块。

## 执行流程

1. 先询问用户要重置的是哪一侧：
   1. VPS 服务端
   2. 路由器客户端
   3. 两侧都重置
2. 若用户要求重置 VPS 服务端：
   1. 调用 `openclaw_reset_frps`。
   2. 明确告知这会停止服务端、清理配置和相关文件。
3. 若用户要求重置路由器客户端：
   1. 调用 `clawwrt_list_devices` 获取在线设备。
   2. 让用户明确确认目标 `device_id`。
   3. 若用户要求全局关闭客户端功能，调用 `clawwrt_disable_xfrpc_service`。
   4. 若用户要求清空该设备上的全部映射，调用 `clawwrt_del_xfrpc_tcp_service` 且不传 `name`。
4. 若用户要求重置后重新部署：
   1. 重置完成后回到 `references/status.md`。
   2. 按四阶段主流程重新开始，不沿用旧 token、旧端口或旧客户端参数。

## 规则

1. 涉及删除、禁用、清空等动作时，必须先让用户明确确认目标范围。
2. 未确认 `device_id` 时，不得对任何在线设备执行客户端重置。
3. 重置不是默认主流程；只有用户明确提出时才执行。

## 成功输出

至少包含：

1. 已重置的侧别
2. 已执行的 API
3. 受影响的设备或服务端范围
4. 下一步建议：重新开始四阶段主流程或结束
