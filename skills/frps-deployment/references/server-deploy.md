# 部署或修复 VPS 内网穿透服务端

## 适用场景

服务端未安装、未运行，或 token 为空时使用。

## 固定入口

先调用 `openclaw_get_frps_status`。

## 执行流程

1. 检查当前状态。
   1. 如果服务端状态正常且 token 非空，直接结束本模块并进入 `references/client-deploy.md`，不要再进入部署或重置分支。
2. 调用 `openclaw_deploy_frps`。
   1. 工具会在未传 token 时自动生成。
   2. 默认监听端口由工具层处理，文档无需重复强调。
3. 部署后再次调用 `openclaw_get_frps_status`。
4. 如果工具返回后 token 仍为空，停止后续流程，并按工具返回结果提示用户检查服务端部署异常；不要在技能层重复发起额外部署。
5. 服务端正常后，再调用 `openclaw_get_vps_public_ip` 获取公网 IP。
6. 向用户输出监听端口、认证密钥和公网 IP，并提醒检查安全组或防火墙。
7. 若用户要用域名，把域名作为 `server_addr`；否则默认使用公网 IP。

## 规则

1. 不在服务端部署前询问客户端参数。
2. 不猜测公网 IP，只用接口返回值或用户明确提供的域名。
3. 失败就停止，不进入客户端部署。

## 成功输出

至少包含：

1. 服务端部署结果
2. 监听端口
3. 认证密钥
4. 公网 IP 或确认的域名
5. 下一步建议
